# WM4 song list

A Key 찬양 4곡의 송폼, 연결 안내 및 악보를 제공하는 HTML 페이지

## GitHub Pages

저장소 Settings → Pages → Build and deployment에서 `Deploy from a branch`, `main`, `/ (root)`를 선택

예상 주소: https://SincerityDani.github.io/Onnuri/

## 구성

- `index.html`: 콘티 페이지
- `assets/`: 순서대로 연결된 악보 4장
- 다크 / 라이트 모드, 인쇄 / PDF 저장, 악보 원본 보기 지원
- 직접 선택한 대체 악보는 현재 화면에서만 사용하며 저장소에 업로드되지 않음
- 페이지 스타일은 Tailwind CSS CDN을 사용하므로 인터넷 연결 필요
