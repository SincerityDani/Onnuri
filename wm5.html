01 · C KEY

주님 말씀하시면

절
“주님 말씀하시면” → “오 주님 나를 이끄소서”
후렴
“뜻하신 그곳에 나 있기 원합니다” → “주님 나라와 그 뜻을 위하여”
엔딩
후렴 반복 후 “오 주님 나를 이끄소서”
  1. 절을 2회 부른다
  2. 후렴을 2회 부른 뒤 엔딩 구절로 마무리한다
  3. 4마디 간주를 연주한다
  4. 절 1회 → 후렴 2회 → 엔딩 순서로 진행한다
  5. 2번 곡의 처음 “날이 저물어 갈 때”로 바로 연결한다

1회차는 절 2회, 2회차는 절 1회. 두 회차 모두 후렴을 2회 부른 뒤 “오 주님 나를 이끄소서”로 마무리한다.

02 · C KEY

주가 일하시네

1절
“날이 저물어 갈 때” → “내가 고백해 여호와 이레”
2절
“우리 모인 이곳에” → “모두 고백해 여호와 이레”
후렴
“주가 일하시네” → “신뢰하며 걷는 자에게”
  1. 별도 전주 없이 1번 곡에서 바로 1절로 들어간다
  2. 1절 → 2절을 이어 부른다
  3. 후렴 전체를 3회 연속 부른다
  4. 세 번째 후렴 뒤 “신뢰하며 걷는 자에게”만 2회 더 부르고 곡을 완전히 마친다
  5. 멘트 또는 짧은 호흡 후 D키로 전환한다

1절 → 2절 → 후렴 3회. 마지막 “신뢰하며 걷는 자에게”는 세 번째 후렴 끝의 1회에 2회를 더해 총 3회 부른다.

03 · D KEY

약할 때 강함 되시네

1절
“약할 때 강함 되시네” → “주 나의 모든 것”
2절
“십자가 죄 사하셨네” → “주 나의 모든 것”
후렴
“예수 어린 양” → “존귀한 이름”
  1. D키 인트로 후 1절을 시작한다
  2. 1절 → 후렴 1회 → 2절 → 후렴 1회 순서로 진행한다
  3. 두 번째 후렴이 끝나면 D코드를 유지한다
  4. 인도자 사인에 4번 곡의 처음 “나 무엇과도 주님을”로 연결한다

후렴은 각 절 뒤에 한 번씩 부른다. 한 번의 후렴 안에서 “예수 어린 양 존귀한 이름”을 2번 부른다.

04 · D KEY

나 무엇과도 주님을

절
“나 무엇과도 주님을 바꾸지 않으리” → “주의 얼굴 보기 원합니다”
후렴
“주님 사랑해요 온 맘과 정성 다해” → “하나님의 신실한 친구 되기 원합니다”
  1. 3번 곡에서 이어 받아 절 “나 무엇과도 주님을 바꾸지 않으리”부터 시작한다
  2. 절 전체를 3회 연속 부른다
  3. 후렴 “주님 사랑해요 온 맘과 정성 다해”를 3회 연속 부른다
  4. 마지막 “하나님의 신실한 친구 되기 원합니다”로 마무리한다

절 3회 → 후렴 3회 순서로 진행한다. 절은 “주의 얼굴 보기 원합니다”, 후렴은 “하나님의 신실한 친구 되기 원합니다”까지가 한 번이다.
